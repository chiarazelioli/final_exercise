The goal is to perform genomic prediction including multiple random effects, namely additive genetic and environmental, and adding custom penalization on them. For this task, we simulate phenotypic data following the marker-based model formulation. We simulate all these effects starting from a matrix of SNPs, which has dimension 3032x100000. Clearly we cannot fit a model like that, thus we do PCA of the SNP matrix, to overcome the dimensionality problem. Then, we fit a LMM via mgcv() , because our goal is to impose custom penalization on different random effects. The other readme contains more info, i didnt have much time to write a complete one xx
